================================================================================
                        TROUBLESHOOTING
================================================================================

Problem: GPU not detected
  → Restart your computer (REQUIRED after CUDA install)
  → Verify CUDA installed: C:\Program Files\NVIDIA GPU Computing Toolkit\
  → Verify cuDNN extracted in CUDA folder

Problem: "CUDA not found"
  → Settings → System → About → Advanced system settings
  → Environment Variables → New
  → Variable: CUDA_PATH
  → Value: C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.4
  → Restart computer

Problem: Still using CPU after setup
  → pip uninstall tensorflow -y
  → pip install tensorflow[and-cuda] --force-reinstall
  → Restart computer

Problem: GPU runs out of memory
  → In train_gpu.py, change:
    BATCH_SIZE = 16  (instead of 32)
